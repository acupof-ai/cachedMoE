✅ **`--cache-slots` 已经不用给了**（Track H1a 生效，本实例就是这样起的）：
`auto` 自己封顶到 5,000 槽（`DEEPMOE_CACHE_SLOT_CAP` 可改，0 = 关），
并且建完 slab 池先提交一个空命令缓冲探一下，被拒就退 200 槽重建（最多 5 次）。
本次就绪横幅：`expert cache 87.6 GiB (5000 slots)`。

✅ **GPU prefill 现在默认开着，不用给 `--gpu-prefill-min`**（Track PF，docs/p3_chat.md §8）：
引擎默认 `gpu_prefill_min = 512`（`runtime/session.h`），`server.py` **什么都不传**。
1,118-token 的新 prompt 在 5,000 槽热 cache 上 **168.8 s → 28.6 s（25.6 ms/token，5.9×）**。
续写（reuse > 0）也上 GPU，靠的是「reuse 不值钱就扔掉、整个 prompt 重新 prefill」这条规则
（`--gpu-prefill-speedup`，默认 6.0，`<= 1` 关）：1,514-token 的第二轮 **70.5 → 35.5 s（2.0×）**。
要关掉回到旧行为：`--gpu-prefill-min 0`（这个 0 以前是空操作，Track PF 一起修了）。

✅ **`.pkv` 也不用在重启前清了**（Track H1b 生效）：恢复失败——分配被拒 / 损坏 / 尺寸不符——
是一条 warning + 冷 prefill，那一轮照常跑完，失败的那份 `.pkv` 被删掉。
本次启动前仍然顺手清了一次，日志里 `serve: restored 374 tokens from kv disk` 是之后写的。

  ✅ **这个文件现在真的有东西了**（Track PF，docs/p3_chat.md §8.1）：以前它只有两行，
  因为 `core/log.h` 写的是 `FILE* stdout`，而 serve 把 stdout 让给协议之后 fd 1 虽然
  指向 stderr，那个 `FILE*` 在 pipe 上是**全缓冲**的、`emit` 只在 `>= Warn` 时 flush ——
  每条 `log_info` 都躺在没人 flush 的 4 KiB 缓冲里，进程被 `Stop-Process` 杀掉时一起没。
  现在 logger 有进程级 sink（serve 调 `set_log_stream(stderr)`）并且**每行 flush**，
  开机就有 26 行，而且**每一轮对话都有一行 session 决策**：

      [INF] session: prompt N tokens, history H, common prefix C -> reuse R (cold|extend|rollback|reset|gpu-recompute), S to prefill (gpu_prefill_min 512)
      [INF] session: S tokens prefilled on the GPU in T s (X ms/token)

  `预填充 … ms/token` 那一行慢的时候，先看这里。

.pkv 前缀 KV 缓存
-----------------
  目录  %LOCALAPPDATA%\deepmoe\kv\D__models_DeepSeek-V4.1-Flash

  ✅ **不用再在重启前清空了**（Track H1b，本实例的 exe 已经带上）：`.pkv` 恢复失败——
  分配被拒 / 损坏 / 尺寸不符，任何错误码——现在是一条 warning + 冷 prefill，
  那一轮照常跑完，失败的那份 `.pkv` 自己被删掉。见 docs/p4_kv_ux.md §5.2。

  它以前是致命的：默认 cache 大小下 path A 会被 expert cache 占满
  （`slab pool: path A full after 34 slabs`），恢复拿不到显存就报
  `serve: kv-disk restore failed: internal: vkQueueSubmit2 failed (-2)`，
  而这个错误**直接杀掉那一轮对话**（抛进 tools/chat.py:186）。

  注意「不致命」不等于「能恢复」：path A 满时恢复仍然拿不到显存，
  那一轮付完整 prefill（STATUS §7 第 2 项的 ②）。要手动清的话还是这一行：

      Remove-Item "$env:LOCALAPPDATA\deepmoe\kv\D__models_DeepSeek-V4.1-Flash\*.pkv"
