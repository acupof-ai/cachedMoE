When liquid refrigerant flows into the freezer coils, it's under low pressure, so it boils easily — and boiling absorbs heat, just like sweat evaporating off your skin cools you down. The refrigerant grabs heat from your food and turns into a gas.

Next, a compressor squeezes that gas, raising its pressure and temperature. Squeezing makes it hot — like a bike pump warming up when you inflate a tire. Now the refrigerant is hotter than your kitchen, so it flows through coils on the back of the fridge, where that heat escapes into the room.

```python
from typing import List, Tuple

def merge_intervals(intervals: List[Tuple[int, int]]) -> List[Tuple[int, int]]:
    """
    Merge overlapping closed intervals.

    Intervals are treated as closed, so [1, 3] and [3, 5] are considered
    overlapping and will be merged into [1, 5].

    Args:
        intervals: A list of (start, end) tuples.

    Returns:
        A new list of non-overlapping (start, end) tuples, sorted by start.

    Examples:
        >>> merge_intervals([(1, 3), (2, 6), (8, 10), (15, 18)])
        [(1, 6), (8, 10), (15, 18)]
        >>> merge_intervals([(1, 4), (4, 5)])
        [(1, 5)]
        >>> merge_intervals([])
        []
    """
    if not intervals:
        return []

    # Sort by start time; O(n log n)
    sorted_intervals = sorted(intervals, key=lambda x: x[0])

    merged: List[Tuple[int, int]] = [sorted_intervals[0]]

    for start, end in sorted_intervals[1:]:
        last_start, last_end = merged[-1]
        if start <= last_end:  # closed intervals: touching counts as overlap
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))

    return merged
```

### Time complexity

Sorting the input dominates the runtime at **O(n log n)**, where *n* is the number of intervals. The subsequent single pass to merge overlapping intervals runs in **O(n)**, so the overall time complexity is **O(n log n)** with **O(n)** auxiliary space for the output list.
